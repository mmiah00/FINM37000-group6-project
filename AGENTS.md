# Working in this repository

This is a shared team repository. Each member owns the modules and issues assigned to them.

Change only the files the current task needs. Do not edit, reformat, or "fix" another member's modules, tests, data documentation, or configuration unless the task explicitly asks you to. If you notice a problem outside your task, raise it in a pull request comment or an issue.

Automated review, lint, test, and documentation fixes follow the same rule. Stay inside the files the task already changes.

Keep unrelated whitespace and formatting changes out of pull requests.
